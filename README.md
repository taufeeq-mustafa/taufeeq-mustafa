### What I do

I'm a software engineer who builds **AI products that hold up in front of real customers**. I take a messy business problem, such as camera footage nobody audits, contracts nobody summarizes, or tickets that fall through the cracks, and turn it into a working system that plugs into the tools a team already uses.

- 🎯 **Customer-first:** I start from the workflow, not the model.
- 🛡️ **Trustworthy AI:** I build guardrails so LLM output is grounded, verified and auditable.
- 🔌 **Integrations:** Salesforce, third-party APIs, cloud services. I make systems talk to each other.
- 🚀 **End to end:** Backend, AI layer, dashboards and deployment.

Currently **Backend AI Engineer @ 1PercentLabs**. Looking for **Forward Deployed Engineer, GTM Engineer and Product Engineer** roles.

### Things I've built

**👁️ AI Service Verification from Live CCTV**<br>
Turns live camera streams into auditable proof that a service actually happened. YOLOv11s detection with per-camera tuning, zone-polygon boundary filtering, dwell/gap session logic and movement checks to reject false positives, plus an optional vision-language-model confirmation step that fails open when unsure.
<br>`YOLOv11` `Computer Vision` `VLMs` `Python`

**📊 Grounded AI Analysis Engine**<br>
Converts live client service and contract data into written reports a client can trust. It confirms company identity before researching, verifies every source link against pages it actually opened, and computes metrics in code so the model interprets them but never invents them.
<br>`LLMs` `Anthropic` `OpenAI` `Anti-hallucination` `Django`

**📄 9-Stage AI Document Pipeline**<br>
A Django + Celery pipeline that takes documents from upload to approved summary. Validation rules return every error at once, and the AI summary is cross-checked against PostgreSQL figures to the cent before it moves forward. Mismatches are saved as diffs and flagged for review.
<br>`Django` `Celery` `PostgreSQL` `LLMs`

**☁️ Salesforce Automation & Sync**<br>
A customer-portal submission triggers a Salesforce Flow that creates the ticket and emails the customer an acknowledgment automatically. Also built a custom Lightning Web Components dashboard on Apex, with two-way sync between Salesforce and the app backend.
<br>`Salesforce` `Apex` `LWC` `Flows` `REST APIs`

**💬 RAG Chatbot Microservice**<br>
LangChain + Llama-3 + FAISS retrieval service, packaged with FastAPI and Docker, serving about 500 queries a day at under 1.5s average response time.
<br>`RAG` `LangChain` `FAISS` `FastAPI` `Docker`

**🧠 Talking Therapy Chatbot (Final Year Project)**<br>
Fine-tuned BlenderBot-400M for supportive, domain-specific conversation, served through a real-time FastAPI API with vector-store memory across sessions.
<br>`Fine-tuning` `Hugging Face` `NLP` `FastAPI`
