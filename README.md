## `> about`

I build **AI products that hold up in front of real customers**. I start from the workflow, not the model. I take problems like camera footage nobody audits, contracts nobody summarizes, and tickets that fall through the cracks, and turn them into systems that plug into the tools a team already uses.

## `> deployed_systems`

<table>
<tr>
<td width="50%" valign="top">

### `01` Vision Verification Engine
Turns live CCTV streams into auditable proof that a service actually happened. YOLOv11s detection with per-camera tuning, zone-polygon boundary filtering, dwell and gap session logic, movement checks to reject false positives, and an optional VLM confirmation step that fails open.

`YOLOv11` `Computer Vision` `VLMs` `Python`

</td>
<td width="50%" valign="top">

### `02` Grounded AI Analysis Engine
Converts live client service and contract data into reports a client can trust. Confirms company identity before research, verifies every source link against pages it actually opened, and computes metrics in code so the model interprets them but never invents them.

`LLMs` `Anthropic` `OpenAI` `Django`

</td>
</tr>
<tr>
<td width="50%" valign="top">

### `03` 9-Stage AI Document Pipeline
Django and Celery pipeline from upload to approved summary. Validation rules return every error at once. The AI summary is cross-checked against PostgreSQL figures to the cent before it advances, and mismatches are saved as diffs and flagged.

`Django` `Celery` `PostgreSQL` `LLMs`

</td>
<td width="50%" valign="top">

### `04` Salesforce Automation and Sync
A portal submission triggers a Salesforce Flow that creates the ticket and emails the customer an acknowledgment automatically. Custom Lightning Web Components dashboard on Apex, with two-way sync between Salesforce and the app backend.

`Salesforce` `Apex` `LWC` `Flows`

</td>
